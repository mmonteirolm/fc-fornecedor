# Ferramenta Consulta Fornecedores

Crie uma página onde vão ter duas seções:

Uma delas é para um redirecionamento para o site do governo onde são verificados os fornecedores adeptos ao Simples Nacional (link fornecido no arquivo anexo).

Na próxima seção vão ficar os links de acesso para a consulta da inscrição estadual, divididos em 5 seções por região do país:
- Região Sul: PR, RS, SC
- Região Sudeste: ES, MG, RJ, SP
- Região Centro-Oeste: DF, GO, MS, MT
- Região Nordeste: AL, BA, CE, MA, PB, PE, PI, RN, SE
- Região Norte: AC, AM, AP, PA, RO, RR, TO

Cada um destes estados deve ter sua bandeira em cima e o hiperlink abaixo com o link de acesso da consulta da inscrição estadual de cada estado, usando os links fornecidos no arquivo anexo. Inclua busca por nome/sigla do estado.
